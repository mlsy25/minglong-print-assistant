# 明隆打印助手

**打印机扫完，文件直接落到电脑上。** 不用插 U 盘，不用跑到机器前按「保存」，也不用装驱动、装插件。

装一次，开机自动在后台待着。谁扫了东西，电脑这边立刻就有了。

## 这是什么

明隆条幅锦旗丝印厂自用的小工具，做的是一件很具体的事：把打印机、复印机、扫描仪上的「扫描到 FTP」用好。

这类机器几乎都支持把扫描件直接推到一台电脑上，但配置起来总要人教一遍。这个工具做的就是替你把那台电脑准备好——插上网线，填个地址，从此扫完就在。

## 适合谁用

- 打印店里那台带扫描的复印机，想让扫描件直接进电脑
- 需要把纸质单据、合同、身份证扫描件归档到固定目录
- 不想为了「扫描到电脑」去装一堆厂商套件

## 下载安装

到 [Releases](../../releases) 下载最新的 `MingLongPrintAssistant-Setup-x.y.z.exe`，双击装完即可。

- 不需要管理员权限，不会往系统目录里塞东西
- 装在 `%LOCALAPPDATA%\Programs\MingLongPrintAssistant`，装的时候可以改位置
- 想卸载，开始菜单里点「卸载 明隆打印助手」

**系统要求**：Windows 10 或 Windows 11，64 位。

## 三步上手

装完之后打开程序，首页会显示一个地址，比如 `192.168.1.8:2121`。照着填到打印机里：

1. **在程序里确认接收目录**：设置 → 接收目录，就是扫描件存放的位置，默认在「文档\明隆扫描件」
2. **在打印机里设「扫描到 FTP」**：服务器填上面那个 IP，端口填 `2121`，用户名和密码用设置页「FTP 设置」里的那组，路径填 `/scan`
3. **扫一张试试**：扫描后程序列表会立刻多出一行，说明通了

账号密码可以在设置页里改成你自己习惯的，改完重新启动一下 FTP 服务即可。

## 功能一览

**收到文件就有记录**

列表实时显示收到的文件，带今日份数。点一下就能打开，也能直接跳到接收目录。

**不用记地址**

设置页里能看到当前 FTP 地址，改端口、改账号密码都在这里，改完即生效。

**不打扰你**

全屏看视频、打游戏、开会投屏的时候，程序不会弹任何提示，自动检查也会往后推。这是默认开着的，不用管它。

**版本会自动更新**

有新版本时，程序在后台悄悄下好，下完才告诉你一声。你可以选「稍后提醒」，一小时后再说。

**开机就在，也可以不在**

开机自启默认是关的，需要的话自己去设置里打开。

## 收不到文件怎么办

先看这三条，八成能解决：

1. **打印机和电脑在同一个网络**吗？地址要填电脑的局域网 IP（程序里显示的那个），不是公网地址
2. **防火墙放行了吗**？第一次用需要在 Windows 防火墙里放行入站 TCP `2121` 和 `30000–30010`
3. **账号密码填对了吗**？打印机里填的用户名、密码，必须和程序设置页里的完全一致，注意大小写

还是不行，把程序「设置 → 版本与维护 → 运行日志」里的内容发出来，一般能直接看出卡在哪一步。

## 常见问题

**扫描件存到哪了？**
「设置 → 接收目录」，点「打开」就能看到。程序区分今日份数和历史文件，找文件不用翻列表。

**能多个打印机一起用吗？**
可以，多台机器指向同一个 IP 和端口就行，收到的文件都会进同一个列表。

**会不会占很多空间？**
程序本体 2 MB 出头，缓存里只放日志和已下载的安装包。收到多少扫描件占多少空间，那是你自己的文件。

**会不会影响电脑性能？**
程序常驻内存很小，平时基本不占用 CPU。它不读取任何其他程序，也不会拦你的键鼠。

**重装系统后要重新配吗？**
要。程序和配置都在本机，重装后重新装一遍、重新填一次打印机那边即可。
