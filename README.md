## 🖥️ 为什么做这个？

店里那台复印机支持「扫描到 FTP」，按说扫完文件就该自己跑进电脑。可每换一台电脑，就得从头配一遍：IP 填什么、端口多少、账号密码在哪、路径写什么，错一个字文件就收不到。配好之后也没人记得住，下回还得再教一遍。

后来干脆写了个小程序，替你把电脑这一头弄利索。用着用着又添了几件：旧扫描件攒多了自动清、文件名按自己的规矩改、客户身份证正反面拼一张 A4 就能打。

它现在做的不只是接收文件，以后还会更多——一个人维护，缺什么加什么。

## ✨ 主要功能

- 📥 **扫描件直达电脑** ：复印机扫完，文件立刻出现在列表里，带今日份数，点一下就能打开

- 🗂 **按自己的规则改名** ：`{原名}` `{扩展名}` `{IP}` `{日期}` `{时间}` `{序号}` `{用户名}` 随便拼，边上就有预览，重名自动补 `-1`、`-2`

- 🧹 **旧扫描件自动清理** ：超过保留天数的删掉，文件夹留着；启动时清一次，连着开满一天再补一次

- 🪪 **身份证正反面拼 A4** ：两张照片——手机拍的、扫描的都行——自动找边、拉正、铺满标准尺寸、削成真卡的圆角，正面在上反面在下，中间留空

- ✂️ **裁得不准能修** ：点「调整区域」拖四个角；照片太花、没找着证件，它会主动问你要不要手动框

- ✍️ **水印随手改** ：预览右上角拨开关、改文字，回车即生效，默认不压

- 🖨 **打印就是标准尺寸** ：A4 版面按实际尺寸排好，打印时选「实际大小 / 100%」就行

- 🪟 **托盘常驻** ：能设成点 × 收进托盘、接收照常跑；也能设成直接退出，随你

- 🙈 **不打扰** ：全屏看视频、打游戏、投屏开会时一声不吭，自动检查也往后推

- 🔄 **后台自动更新** ：新版本悄悄下好，下完才问你要不要装，下的是差异包，一般几百 KB

- 🆘 **软件内帮助页** ：连不上、收不到、打不开，逐条「现象 → 原因 → 怎么办」，不用上网翻答案

## 📥 下载与安装

| 系统 | 下载 | 文件 |
|---|---|---|
| Windows 10 / 11 (64 位) | [下载 Windows 版](../../releases/latest) | `MingLongPrintAssistant-Setup-x.y.z.exe`（完整安装包，自带运行时） |
| 已经装了旧版的 | 程序里点「设置 › 版本与维护 › 检查更新」 | `MingLongPrintAssistant-update-x.y.z.zip`（差异包，自动更新用） |

**Windows**

1. 下载 `Setup-x.y.z.exe`，双击装完就能用。不需要管理员权限，装在当前用户目录里，不往系统目录塞东西。想卸载，开始菜单里点「卸载 明隆打印助手」。

2. 若提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**（安装包没有购买代码签名证书）。

3. 装完打开，首页会显示一个地址，比如 `192.168.1.8:2121`，这就是复印机那边要填的服务器。

4. 到复印机上选「扫描到 FTP」，服务器填这个 IP，端口填程序里显示的那个（默认 `2121`），用户名密码照抄「FTP 扫描接收 → 设置」里那组，路径写 `/scan`，保存。

5. 扫一张试试，列表里立刻多出一行，就成了。

复印机那边的设置得在机器自己的面板或网页后台里改，程序改不到那台机器。程序能做的是把它这边要的参数摆给你看，再帮你把防火墙放行。

以后有新版本时程序会提示，点「立即更新」即可，只替换变了的文件，不用重新下载整个安装包。

## ❓ 常见问题

**要装 .NET 吗？要钱吗？**

都不用。.NET 9 运行时已经打在安装目录里，没装 .NET 的电脑也能直接跑；程序免费，没广告，不收集任何东西。

**收不到文件？**

按顺序排查：

1. 复印机和电脑在同一个网里吗？地址要填电脑的局域网 IP（程序里显示的那个），不是公网地址。

2. 防火墙放行了吗？「FTP 扫描接收 → 设置」，端口那一栏下面有个「放行防火墙」，点一下。

3. 账号密码跟程序里那组一字不差吗？注意大小写。

4. 复印机上按了保存吗？不少机器改完不点「保存 / 应用」等于没改。

5. 最近改过端口吗？程序里改了端口，复印机那边也要跟着改，不然它还在往老端口推。

**杀毒软件报毒 / 程序被删了？**

是**误报**。安装包没买代码签名证书，新版本刚发布也没有「信誉」，再加上自动更新会替换自己的程序文件，这些行为容易被安全软件当成可疑。

- **Windows 安全中心**：打开「病毒和威胁防护」›「保护历史记录」，找到被拦的明隆打印助手点 **还原 / 允许**；再到「病毒和威胁防护设置」›「排除项」› **添加排除项 › 文件夹**，选程序所在的文件夹。

- **360 安全卫士**：木马查杀 › 右下角 **恢复区** 里恢复，再到 **信任区** 添加程序文件夹。

- **火绒**：隔离区里恢复，再在「信任区」添加程序文件夹。

建议把程序装在单独的文件夹里（安装器默认就是 `%LOCALAPPDATA%\Programs\MingLongPrintAssistant`），加了排除项以后，自动更新出来的新版本也不会再被删。

**身份证打出来大小不对？**

打印对话框里把缩放选成「实际大小 / 100%」，别用「适应页面」。版面是按 85.6 × 54mm 实际尺寸排的，一缩放就跑偏。

**身份证裁得不干净，边上带杂物？**

点「调整区域」，把四个角拖到证件真正的角上。手机拍的照片背景花、桌上又有白纸的时候，自动识别容易把纸边一起框进来，手动拖一下就准了。

**自动清理会不会把我的文件删光？**

只删超过「保留天数」的文件，文件夹一律保留。天数在「FTP 扫描接收 → 设置」里改，默认 30 天，也能随时点「立即清理一次」。正在传的、刚落地的文件它不碰。

要注意的是删除不进回收站，删了就没了，天数别设得太短。

**扫描件存哪？能改吗？**

默认在「文档\明隆扫描件」。「设置 → 接收目录」里能改，点「打开」直接看到那个文件夹。

**点了 × 程序就没了？**

默认是真退出。想让它在后台一直收，去设置里打开「关闭窗口后留在托盘」，之后点 × 只是收进托盘，双击托盘图标就回来了。

**两台打印机都能用吗？**

能，两部机器都指向同一个 IP 和端口，文件进同一个列表。

**重装系统以后要重新配吗？**

程序得重装一遍，程序里的配置存在本机，也没了。复印机里的设置一般在机器里，还在。

**检查更新显示失败？**

多半是网络连不上 GitHub，过一会儿再试就行，也可以直接到 [Releases](../../releases) 下最新的安装包覆盖安装。设置了开机自启、托盘的都不受影响。

**遇到问题怎么反馈？**

点「设置 › 版本与维护 › 运行日志」，会直接打开日志文件夹并选中当天的文件，把那份发到 [Issues](../../issues)，写上复印机型号和现象，一般就能看出卡在哪一步。
